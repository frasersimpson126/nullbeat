# NullBeat for Orpheon

An Orpheon / Myspoti extension that uses one configured Eclipse-compatible NullBeat addon for streaming and downloads.

## Features

- One private **NullBeat manifest URL** setting.
- Streaming through the addon's `/search` and `/stream/{id}` endpoints.
- Downloads through the same NullBeat resolver, with the download flag enabled.
- ISRC-first matching when the addon advertises the capability, followed by strict title + artist matching and a 10-second duration tolerance.
- Direct stream URLs are used when present in search results only if they are still returned by the stream endpoint; the stream endpoint remains the final resolver.
- Connection test checks the manifest and sample search endpoint.
- Playback origin diagnostics distinguish NullBeat streams from downloaded tracks.
- Cache visibility: when NullBeat's stream response identifies a TorBox cache hit, the player source label and download provider label say **TorBox cached**. Otherwise the response title/quality is shown where available.

## Quality

NullBeat controls quality. This extension intentionally has **no quality selector** and does not override NullBeat's configured quality or duplicate its settings. If your NullBeat manifest URL contains a token that encodes quality, keep using the complete URL generated by NullBeat.

## Install / configure

1. Install the extension in Orpheon.
2. Open **NullBeat for Orpheon** settings.
3. Paste the complete HTTPS `manifest.json` URL generated by your NullBeat instance into **NullBeat manifest URL**. The URL may contain a private token; do not share it publicly.
4. Press **Test NullBeat connection**.
5. Enable this extension as an audio source and download source in Orpheon.

The URL field is a secret setting and is not written to logs. The extension requests the configured host over HTTPS. The extension's network permission is broad because a self-hosted NullBeat instance can use a custom domain; install only if you trust the URL you enter.

## Cache reporting limitation

NullBeat reports cache information in the stream response title (for example, a title containing `Torbox Cached`) and may include an `infohash` or `cached` flag. The extension surfaces that information when present. It does not claim to know whether an arbitrary track is cached before requesting its stream. Orpheon playback events also expose whether the current audio origin is a stream, a download, or a local file.

## Compatibility

- Requires a public HTTPS Eclipse-compatible NullBeat manifest URL. Orpheon's extension HTTP client does not follow redirects or send browser cookies.
- Supports direct HTTPS audio URLs in FLAC, M4A/MP4, AAC (mapped to M4A), and MP3 formats.
- HLS/DASH manifests and redirect-only stream URLs are not passed through.
- Matching is deliberately strict to avoid playing a different recording.
- Spotify scrobbling is left to Orpheon's built-in Spotify mirroring option; this extension does not implement a second scrobbling path.

## Development

Package and validate with the official Orpheon extension CLI:

```sh
myspoti-ext check .
myspoti-ext pack .
```

The package must contain `manifest.json`, `main.js`, and optionally `README.md` and a licence file at its root.
